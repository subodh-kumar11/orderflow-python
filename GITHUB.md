# Working with the GitHub repository

Repository: https://github.com/subodh-kumar11/orderflow-python

The repository is private. Invite your reviewer through GitHub's repository access settings if they need to review it. Do not send API keys or local database files.

For ongoing development, clone the published repository using your normal authenticated Git installation or GitHub Desktop:

```sh
git clone https://github.com/subodh-kumar11/orderflow-python.git
cd orderflow-python
```

Follow the README to install dependencies and run the application. Create a feature branch, commit your changes and push it normally. GitHub Actions runs on pushes and pull requests.

The generated local deliverable was prepared independently and uploaded using the signed-in GitHub browser session. Its local Git history differs from the published repository's import history. Use a fresh clone for future Git work rather than force-pushing the generated folder over the remote history. The downloadable source ZIP contains application source, not Git history, environments, dependencies, databases or secrets.
